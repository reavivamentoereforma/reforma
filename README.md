# reforma
Reavivamento e Reforma é um movimento sagrado vocacionado a proclamar o evangelho eterno a toda nação e tribo, despertando nas almas o ardente anseio de conhecer a Cristo. Nosso propósito é conduzir *as pessoas* a uma profunda renovação da vida espiritual pelo Espírito Santo e a um aperfeiçoandod o caráter à imagem do Mestre.
